# ملف المشروع الكامل — الأكواد والتصميم ولوحة التحكم

نظام إدارة المشاريع للمؤسسة
`Project Management & Operations System`

هذا الملف يشرح بشكل كامل:

1. **الأكواد** — بنية المشروع وكل ملف وما وظيفته.
2. **تصميم المشروع** — نظام التصميم (الألوان، الخطوط، المكونات، التجاوب، RTL).
3. **لوحة التحكم** — كل عنصر فيها ومصدر بياناته.

---

## 1. نظرة عامة

نظام ويب مؤسسي لإدارة المشاريع والفرق والمهام والميزانيات والمواعيد والتقارير، بواجهة عربية (RTL) متجاوبة.

| الطبقة | التقنية |
| --- | --- |
| الواجهة (Frontend) | Vite + React + TypeScript + Tailwind CSS + Chart.js |
| الخادم (Backend) | Node.js + Express REST API |
| قاعدة البيانات | PostgreSQL (WASM عبر PGlite، تعمل داخل خادم الـ API مع حفظ البيانات على القرص) |

التدفق العام:

```
Frontend  →  REST API  →  Business Logic  →  Database
```

الواجهة لا تتصل بقاعدة البيانات مباشرة، وكل الصلاحيات تُفرض على الخادم.

## 3. تصميم المشروع (نظام التصميم)

### 3.1 الخط

- **Tajawal** (خط عربي) هو الخط الأساسي، مع بدائل النظام.
- العناوين: سميكة `font-extrabold` / `font-bold`.
- النصوص: `font-semibold` / `font-medium` حسب الأهمية.

### 3.2 الألوان

| الاستخدام | اللون |
| --- | --- |
| اللون الرئيسي (أزرار/روابط/تنقّل نشط) | **Indigo** — `#4f46e5` (indigo-600) |
| خلفية الصفحة | **Slate-100** — `#f1f5f9` |
| خلفية البطاقات | أبيض `#ffffff` |
| نص رئيسي | **Slate-900** — `#0f172a` |
| نص ثانوي | **Slate-500** — `#64748b` |
| حدود | **Slate-200** — `#e2e8f0` |
| الشريط الجانبي | **Slate-900** — `#0f172a` |

ألوان الحالات (Status):

| الحالة | اللون |
| --- | --- |
| مكتمل / مكتملة | أخضر `emerald` |
| قيد التنفيذ | أزرق `indigo` / `blue` |
| مخطط له / قيد المراجعة | سماوي `sky` / بنفسجي `purple` |
| متوقف / عالية / متوسطة | كهرماني `amber` |
| ملغى / حرجة / خطأ | وردي `rose` |
| مسودة / لم تبدأ | رمادي `slate` |

### 3.3 المكونات (من `components/ui.tsx`)

| المكوّن | الوصف |
| --- | --- |
| `Button` | أزرار بعدة أشكال: أساسي/ثانوي/خطر/شفاف/محدد + حالة تحميل |
| `Badge` | شارة حالة/أولوية ملونة |
| `Card` | بطاقة بعنوان وزر إجراء اختياري |
| `PageHeader` | عنوان الصفحة + الوصف + أزرار الإجراءات |
| `StatCard` | بطاقة مؤشر رقمي (أيقونة + قيمة + تسمية) |
| `Modal` | نافذة منبثقة (تُغلق بزر Escape) |
| `ConfirmDialog` | تأكيد العمليات الخطرة |
| `Field / Input / Select / Textarea` | حقول النماذج |
| `SearchInput` | حقل بحث |
| `EmptyState` | حالة "لا توجد بيانات" |
| `Pagination` | ترقيم الصفحات |
| `Toast / Toaster` | رسائل النجاح/الخطأ العائمة |
| `Spinner` | مؤشر تحميل |

### 3.4 الشكل العام

- **الزوايا**: `rounded-lg` للأزرار والحقول، `rounded-xl` للبطاقات، `rounded-full` للشارات والصور.
- **الظلال**: `shadow-sm` خفيف على البطاقات.
- **الحواف**: حدود `slate-200` بسمك 1px.
- **الاتجاه**: `rtl` — الشريط الجانبي على اليمين، والنصوص محاذاة لليمين.

### 3.5 التجاوب (Responsive)

- الشريط الجانبي يتحول لقائمة منزلقة على الشاشات الصغيرة (زر قائمة في الرأس).
- شبكات KPI: عمودان على الهاتف، أربعة أعمدة على الشاشات الكبيرة.
- الجداول قابلة للتمرير أفقياً، ولوحة كانبان تدعم التمرير الأفقي.
- الرسوم البيانية قابلة للقراءة على الهاتف.

## 4. لوحة التحكم (Dashboard)

المسار: `/` — الملف: `src/pages/Dashboard.tsx`
المصدر: `GET /api/dashboard`

### 4.1 الترويسة

- ترحيب بالاسم الأول للمستخدم: «مرحباً، أحمد 👋».
- وصف ثابت: «نظرة عامة على المشاريع والمهام والميزانيات».

### 4.2 بطاقات المؤشرات (8 KPI Cards)

| المؤشر | القيمة |
| --- | --- |
| إجمالي المشاريع | `kpi.projects.total` |
| المشاريع النشطة | `kpi.projects.active` |
| المشاريع المتأخرة | `kpi.projects.overdue` |
| المهام المكتملة | `kpi.tasks.completed` |
| إجمالي المهام | `kpi.tasks.total` |
| المهام المتأخرة | `kpi.tasks.overdue` |
| إجمالي الميزانية | `kpi.budget` |
| المتبقي من الميزانية | `kpi.remaining` |

### 4.3 الرسوم البيانية

| الرسم | النوع | البيانات |
| --- | --- | --- |
| توزيع حالات المشاريع | Doughnut | `charts.project_status` |
| توزيع حالات المهام | Doughnut | `charts.task_status` |
| المهام الجديدة (آخر 6 أشهر) | Line | `charts.monthly_tasks` |
| الميزانية مقابل المصروفات | Bar | `/api/reports/financial` |

### 4.4 القوائم

| القائمة | المصدر |
| --- | --- |
| المواعيد القادمة (المهام) | `/api/tasks?sort=due_date&dir=asc` — تُعرض أول 6 مهام غير مكتملة |
| الاجتماعات القادمة | `/api/meetings?upcoming=1` |
| آخر الأنشطة | `recent_activity` (للمدير العام فقط) |

### 4.5 استجابة `GET /api/dashboard`

```json
{
  "kpi": {
    "projects": { "total": 2, "active": 1, "overdue": 0 },
    "tasks":    { "total": 8, "completed": 2, "overdue": 3 },
    "budget": 330000,
    "expenses_total": 26300,
    "remaining": 303700,
    "unread": 2
  },
  "charts": {
    "project_status": [ { "status": "in_progress", "c": 1 } ],
    "task_status":    [ { "status": "completed", "c": 2 } ],
    "monthly_tasks":  [ { "month": "2025-01", "c": 4 } ]
  },
  "recent_activity": []
}
```

> ملاحظة: أرقام «المتأخر» تُحسب على الخادم: `today > due_date` مع `status NOT IN (completed, cancelled)`.

## 5. الوحدات

المصادقة، المستخدمون، الأدوار والصلاحيات (RBAC)، لوحة التحكم، المشاريع، أعضاء المشاريع، المهام، لوحة كانبان، التقويم، الميزانيات والمصروفات، الاجتماعات، الإشعارات، التقارير (مع تصدير CSV)، سجل الأنشطة، البحث والتصفية والفرز، والإعدادات.

### الصلاحيات

1. **مدير النظام** — إدارة المستخدمين والأدوار وسجل الأنشطة.
2. **مدير مشروع** — إنشاء وإدارة المشاريع التي يديرها.
3. **قائد فريق** — إدارة المهام داخل نطاقه.
4. **عضو فريق** — مشاهدة مهامه وتحديث حالتها وتقدمها.
